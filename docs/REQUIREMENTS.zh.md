# 功能需求与验收基线

核对日期：2026-09-08。本文把 [产品功能目录](FEATURES.zh.md) 转成可用于评估实现和回归验收的 feature list。范围是 macOS 浮层产品；功能存在的证据来自当前代码，验收条件表达重构必须保持的行为，并不表示每一项已经通过端到端测试。

## 产品边界与数据所有权

用户在当前桌面或全屏应用上临时展开导图，编辑后收起，继续原来的工作。Swift 外壳负责窗口、快捷键、焦点和本机服务；WKWebView 中的画布负责导图编辑；本机 Node 服务将导图及图片保存在 SQLite 和应用数据目录中。打包后的网页文件随应用安装，修改源码后必须重新安装才能验证热键打开的产品。

导图模型是持久化的业务数据，包含节点、父子关系、交叉连线、格式、布局、笔记、图片和变量。节点在画布上的显示、Markdown 文本表示、输入法中的未确认文字、鼠标拖选和相机视角是不同的状态：输入确认后才能进入模型；文本选区和视角变化不能改变业务内容。导入、导出和撤销必须保持所支持的数据字段。

## 可选能力与继承代码

仓库包含 GitHub 存储、实时协作、托管云分享等代码。它们不等于本机产品已经启用或承诺支持的能力，不能据此为 Mac 用户新增登录依赖。现有分享入口、可选 LLM 请求、Crossref 引用查询和外部链接需要逐项核对可达性，记录在实现评估中。清理继承代码之前必须验证调用关系，不能只根据目录名删除。

当前 `KeyChord` / `ShortcutStore` 实现使用四修饰键的 Hyper-Q，而本地开发约定写的是三修饰键。产品目录应描述实际行为；是否改变默认键位是产品决策，本次性能重构不擅自更改用户配置。

## 质量约束

1. **正确性先于动画效果。** 快速输入后退出、换图、撤销、保存失败都不能静默丢内容。异步任务必须有明确的目标导图和有效期。
2. **成本对应交互。** 鼠标拖选只处理选区；不因移动鼠标而解析整图或保存。每个屏幕帧最多绘制一次拖选高亮，隐藏页面和结束交互后停止工作。
3. **保留真实排版。** 换行、字体粗细、中文、emoji 的选区使用浏览器排版信息；不以固定字符宽度替代实际字符位置。
4. **职责明确。** 文本命中与选区绘制、导图同步、持久化、原生事件转发各有自己的边界。移除被替代且已无调用的实现与注释。
5. **证据可复现。** 单元测试验证状态边界；WKWebView 验证真实排版和事件；正式应用重新安装后验证打包内容和启动。脚本 CPU 耗时不能直接等同于屏幕端到端延迟。

具体问题、修改和验证证据见 [实现评估](IMPLEMENTATION_REVIEW.zh.md)。
